COULEURS ARTICLE -> PANIER -> COMMANDE
=====================================

Fonctionnement ajouté :

1. Sur /article?slug=...
   - le client choisit une couleur.
   - Ajouter au panier et Acheter maintenant mémorisent cette couleur.

2. Dans le panier
   - la couleur apparaît sous le nom de l'article avec cercle + nom + HEX/RGB.
   - un même article avec deux couleurs différentes devient deux lignes différentes.

3. Dans /commande
   - la couleur est conservée dans le résumé.
   - le frontend envoie color { name, hex, rgb } avec chaque article.

4. Backend / base de données
   - scripts/ensureSchema.js ajoute automatiquement au démarrage :
       order_items.color_name
       order_items.color_hex
       order_items.color_rgb
   - le backend vérifie que le HEX commandé existe bien dans les couleurs de l'article.
   - la couleur est figée dans order_items pour préserver l'historique.

5. Admin commandes
   - le détail de la commande affiche le cercle, le nom, HEX et RGB.

6. Notifications / ZR
   - la couleur est ajoutée au résumé WhatsApp et à la description produit ZR Express.

Aucune requête SQL manuelle n'est normalement nécessaire : redémarrer le backend suffit.
